# 服装行业 数字孪生｜织境 Fabric Twin

面向服装制造场景的浏览器 3D 数字孪生演示。

**[在线演示 · GitHub Pages](https://hanhanrin.github.io/garment-digital-twin/)** · [GitHub 源码](https://github.com/HanHanRin/garment-digital-twin)

基于 `build-factory-twin` Skill 的 mock 输入包，使用 Vite + Three.js 制作。源码及几何由本地生成；无需 Blender、Unity、云端服务或外部模型文件。

## 运行

需要兼容 Vite 7 的 Node.js（20.19+ 或 22.12+）。

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:3000/ 。脚本固定使用 3000 端口，端口占用时直接报错。

```bash
npm test
npm run build
```

`dist/` 为可放在静态 HTTP 服务器上的成品。浏览器需要支持 WebGL2。直接双击 HTML 文件不等同于通过 HTTP 启动。

## GitHub Pages 展示

源码保存在 `main`，发布成品保存在 `gh-pages` 分支根目录。仓库 Pages 配置为从 `gh-pages / (root)` 发布，`.nojekyll` 禁用 Jekyll 处理。Vite 使用相对资源路径，以兼容项目子目录。

更新展示页时，先测试并重新构建，再将 `dist/` 的成品提交到 `gh-pages`；只推送 `main` 不会自动更新展示页。

## 演示操作

- 拖动旋转、滚轮缩放；点击设备查看详情，或在设备列表中搜索、选择并聚焦。
- 工具栏可复位全景、切换俯视图、显示全部设备标签和开关物流示意。
- 按区域、状态与名称组合筛选，非匹配设备在场景中淡化。
- 时间轴支持暂停、倍速、从头播放与任意拖动；异常标记会跳转并暂停。
- 三个场景：03:00 A 线断线，05:00 B 线数据离线，07:00 熨烫异常。各自在 04:00、05:30 和 08:00 恢复。
- 小屏通过页头按钮打开设备抽屉；详情显示在场景下方。
- 数据说明中可下载设备 CSV、布局 JSON 和原始状态快照。

## 数据边界

`public/data/` 与 Skill 自带输入包一致。22 个实例、6 个区域、2,662 条状态快照；所有布局、工作站尺寸、工时和遥测都是合成数据。缝纫机系列名称参考厂家公开资料，来源记录在 `machine-catalog.json`。

模型是程序化类别简模，非厂商精确 CAD。单工位完成计数不等于成衣产出。物流动画仅为路径示意；没有实现上下游在制品守恒、订单完成、真实排产、布料力学仿真或实际设备控制。

## 实现与验证

- `src/scene.js`：类别简模、资产 ID 绑定、鼠标拾取、视角、状态与动画。
- `src/replay.js`：离散快照索引、任意时间跳转、历史窗口与组合筛选。
- `src/main.js`：同一模拟时钟驱动列表、场景、详情及事件跳转。
- `tests/replay.test.js`：故障边界、反向跳转、数据离线/恢复、组合筛选和缺失帧检测。

已在浏览器检查设备直接点击、三类异常、离线恢复、搜索与筛选，以及桌面/小屏布局。回放数据仍是独立工位展示模型，不能用于真实产能或维护决策。
